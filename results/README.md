# Project Results

This folder contains visual outputs from the MATLAB implementation of the Eigenfaces method using Singular Value Decomposition (SVD).

- `eigenfaces.png` — Leading eigenfaces computed from the training dataset.
- `face_reconstruction.png` — Original and reconstructed faces using different numbers of components.
- `recognition_accuracy.png` — Calibration and final test results for the evaluated component counts.
- `known_face_recognition.png` — Example of an accepted face match.
- `unknown_face_rejection.png` — Example of an unfamiliar image rejected by the system.
